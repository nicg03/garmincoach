Garmin Sync

First setup

Bring your Garmin data here

This site shows charts and talks to a coach. It cannot log into Garmin for you — that has to happen once on your computer. After that, updates take one command.

  1. 1
    Get the sync app on your computer

    Mac or Windows with Python 3.11+. Download the project, then open a terminal in that folder.

    Download the sync tool →
  2. 2
    Install it (once)

    Paste this into the terminal and wait until it finishes.

    python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-local.txt
playwright install chromium
  3. 3
    Sign in to Garmin (once)

    A Chromium window opens. Log in with your Garmin account, including the MFA code if asked. Close the window when it says you’re done.

    python -m garmin_sync login
  4. 4
    Connect this site

    This opens a browser tab back here. Sign in if asked, then click Connect this computer. No token to copy.

    …
  5. 5
    Publish your history

    Fetches what’s missing from Garmin and sends it here. Use this whenever you want fresh data.

    python -m garmin_sync sync

When this page shows charts, you’re done. Come back anytime — or refresh after a sync.

Load and form

Bars are each day's training load. ATL is the last week of fatigue, CTL the last six weeks of fitness, and form is what's left over: below zero you're accumulating, above zero you're fresh.
