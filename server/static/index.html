FAQ

Things worth knowing

Are accounts separate?

Yes. Each account has its own password, sync and history. Queries always include a user id, so one person's numbers cannot appear on another person's charts.

Is the Garmin connection official?

No. The site signs in the way Garmin's mobile app does. It works today, but it is unofficial. If a datacentre IP gets blocked, the browser extension and the official export zip keep working.

What can a coach see?

Only athletes who link to them. A coach gets a read-only view of that training, can leave notes and assign workouts. They do not get the password or the Garmin login.

How often does data update?

Connected accounts sync every few hours. Opening the site can start a sync when the last one is stale. Older history comes in from Data sources.
